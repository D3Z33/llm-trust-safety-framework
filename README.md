# LLM Trust & Safety Framework

Repositorio academico do projeto LLM Trust & Safety Framework, desenvolvido para a disciplina Cyber Defense Project da Faculdade Impacta.

O repositorio esta organizado para separar os artefatos de entrega academica do codigo do prototipo demonstrativo.

## Estrutura

```text
artifact-generator/  Relatorio, slides, QA, screenshots, roteiros e scripts de geracao.
prototype/           Codigo do prototipo demonstrativo, a ser adicionado posteriormente.
docs/                Documentacao futura do projeto, quando necessario.
```

## Status

- Artefatos finais de relatorio e apresentacao: organizados em `artifact-generator/`.
- Prototipo demonstrativo: estrutura reservada em `prototype/`.
- Publicacao e entrega final: depende da inclusao posterior do codigo e do video final.
