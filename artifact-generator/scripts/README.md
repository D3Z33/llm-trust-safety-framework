# Scripts

Scripts utilitarios para validacao e organizacao dos artefatos.

## Validar artefatos essenciais

Rodando a partir da raiz do repositorio:

```bash
python artifact-generator/scripts/validate_artifacts.py
```

Rodando a partir de `artifact-generator/`:

```bash
python scripts/validate_artifacts.py
```

## Gerar manifesto de artefatos

Rodando a partir da raiz do repositorio:

```bash
python artifact-generator/scripts/generate_manifest.py
```

Rodando a partir de `artifact-generator/`:

```bash
python scripts/generate_manifest.py
```

Os scripts JavaScript nesta pasta foram usados na geracao/exportacao do relatorio e da apresentacao durante a fase de producao dos artefatos.
